# Стадимейт — голосовой агент для выставки

Локальное приложение для Windows 11: посетитель разговаривает с виртуальным учеником Стадимейтом через петличный микрофон и колонку. Голосовой диалог работает на `gpt-live-1` по WebRTC.

## Какой ключ нужен

Нужен только один **OpenAI Project API key** с доступом к `gpt-live-1` и подключённой оплатой API. Отдельный ключ для голосовой модели и отдельный ключ для бэкенда не нужны.

1. Откройте [страницу API-ключей OpenAI](https://platform.openai.com/api-keys).
2. Создайте новый секретный ключ проекта.
3. Скопируйте `.env.example` в новый файл `.env`.
4. Замените значение `OPENAI_API_KEY` в `.env` на свой ключ.

Не вставляйте ключ в `public/app.js`, не отправляйте его в чат и не коммитьте `.env`. Файл уже добавлен в `.gitignore`.

## Первый запуск

Понадобится Node.js 22.6 или новее.

```powershell
npm install
Copy-Item .env.example .env
# Откройте .env в Блокноте и вставьте API-ключ
npm start
```

Затем откройте `http://localhost:3000`. После первой установки можно запускать приложение двойным щелчком по `START_DEMO.cmd`.

## Подготовка оборудования на Windows 11

1. Подключите USB-C-приёмник петлички к ноутбуку и включите передатчик.
2. Откройте **Параметры → Система → Звук → Ввод** и выберите USB-микрофон петлички.
3. Подключите колонку по Bluetooth или кабелю и выберите её в разделе **Вывод**.
4. Откройте приложение в Chrome или Edge и разрешите доступ к микрофону.
5. Перед открытием стенда сделайте один пробный разговор и проверьте громкость.

Важно: колонку держите подальше от петлички и не ставьте максимальную громкость, иначе появится акустическая обратная связь. В браузере включены эхоподавление и шумоподавление, но физическое расстояние всё равно помогает.

## Сценарий посетителя

1. Нажать круглую кнопку с микрофоном и дождаться приветствия.
2. Нажать кнопку, произнести фразу и нажать её ещё раз, когда фраза закончена.
3. Можно снова нажать кнопку, в том числе чтобы перебить Стадимейта.
4. Для полного завершения разговора удерживать кнопку 1,2 секунды. Также работает клавиша `Esc`.

Если кнопку забыли нажать, приложение само завершит одну сессию через 3 минуты.

Примеры:

- «Я объясню тебе теорему Пифагора».
- «Давай проверим, понял ли я фотосинтез».
- «Как StudyMate помогает готовиться к экзаменам?»

## Приватность и стоимость

- `store: false`: приложение не включает сохранение записи GPT-Live.
- Приложение само не пишет аудио или текст в файлы и базы данных.
- `gpt-live-1` тарифицируется по длительности сессии.
- Чтобы не тратить деньги после ухода посетителя, всегда завершайте сессию долгим нажатием.

## Проверка перед выставкой

```powershell
npm run check
```

После этого проведите минимум три живых теста: в тишине, с музыкой/разговорами рядом и с колонкой в том положении, в котором она будет у фигуры. Также подготовьте мобильную точку доступа как резервный интернет.
